# Genuine RC3 gameplay capture checkpoint

Recorded November 11, 2026, from RC3 source in Azahar at normal speed, 400 × 480, 30 fps. The recording-only build adds the local proxy CA, request-error logging and longer network deadlines. The emulator runs with TZ=UTC to avoid BADCERT_FUTURE. TLS peer and hostname validation remain enabled. No diagnostic binary or CA is distributed. Public RC3 packages are unchanged.

- panorama-look.mp4: actual Strasbourg 360° look controls; imagery credited in-app to Eurométropole de Strasbourg, etalab-2.0.
- panorama-move.mp4: R follows a real linked viewpoint; the minimap and panorama change.
- daily-guess.mp4: real Daily Challenge location, map pin, submission, 14,866.6 km distance and zero-point result. The poor guess is genuine. Sydney imagery: Leif Metcalf, CC-BY-SA-4.0; world map NASA Blue Marble.
- terrain.mp4: live Terrarium elevation at 36.1069, -112.1129, zoom 12, with orbit and zoom controls. Elevation: Mapzen/Terrarium.

These recordings do not establish physical 3DS performance, gyro or stereoscopic depth. Buildings timed out through Overpass; the same host request returned HTTP 406. Final editing and panorama-detail verification follow in another checkpoint.
