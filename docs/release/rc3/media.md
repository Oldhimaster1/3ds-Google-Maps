# RC3 media progress

The working emulator profile was recovered rather than recreated. RC3 runs in
Azahar using Xvfb, llvmpipe and the existing virtual SD. The map can display real
satellite tiles prepared in that SD cache. This is cached rendering, not proof of
live service access. Direct requests report hostname-resolution failures.

The README archive remains explicitly labeled as the older map build. New clips
must identify RC3 and Azahar, keep imagery credits visible and avoid claiming
physical performance or stereoscopic depth from a flat video.

Remaining shots: live Street View and movement, view-dependent panorama detail,
terrain/buildings, a completed StreetGuess round and Country Streak record reload.
A trailer or full demonstration must only claim the scenes actually captured.
