# Maps for Nintendo 3DS v2.3.0 Preview 1

- Expand curated StreetGuess from 32 panoramas in 21 countries to 113 in 33.
  New entries include photographer credits, licenses, image hashes and country
  boundary checks. The v2 manifest is preserved; v3 has separate daily records.
- Cache up to four visible high-resolution Google panorama tiles. Load tiles
  sequentially and increase resolution as the view zooms in. Retain the base
  panorama on failures, cancel obsolete requests, and free detail on exit.
- Add nine core-menu languages, including Arabic shaping and bidirectional text,
  plus a bundled Unicode font for international place names and saved places.
- Add optional original synthesized ambient music in Street View and StreetGuess.

## Validation and limits

Host regression suites, dataset integrity checks, Arabic/font tests, audio shim
checks, and CIA/3DSX package-header validation pass. Console rendering, audio,
memory pressure and sustained performance remain unverified for these changes.

Translations cover core menus; some instructions and diagnostics remain English.
Tiled HD applies to the experimental Google provider. Panoramax rounds still use
SD imagery. Coverage is uneven and follows contributor availability. Friend
codes require matching dataset versions; older daily records are retained in
their original file. Back up application data before installing a preview.

This prerelease does not replace the stable release or its permanent install QR.
