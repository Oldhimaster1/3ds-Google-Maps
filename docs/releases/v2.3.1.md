# Maps for Nintendo 3DS v2.3.1

## Changes

- 113 curated StreetGuess panoramas across 33 countries, with credits, licenses
  and verified image hashes. Dataset v2 is preserved; v3 daily records are separate.
- Progressive Google panorama zoom detail: four visible 512px tiles, one worker,
  zoom-dependent resolution and about 2 MiB of resident detail texture data.
  The base panorama remains available during loading or failed requests.
- Nine application languages with 537 translated messages, Arabic joining and
  bidirectional ordering, plus font fallback within mixed-script lines.
- Unicode rendering for saved places, search, StreetGuess and cache statistics.
- Original optional music, saved 0%–100% volume, mute, visible DSP/memory errors
  and explicit retry. Older language settings migrate automatically.

## Tests

35 host suite entries pass, including 4,833 shaped translations with actual font
coverage, 774 translated C format cases, audio lifecycle/failure tests, challenge
codes/dataset validation, and bounded panorama detail loading. CIA/3DSX package
headers and title ID are validated. Azahar 2126.2 runtime checks verified all
nine language selections, volume limits, toggling, persisted settings and mixed
Arabic/Japanese/Latin/Cyrillic text. See [language and music details](../languages-and-music.md).

The test machine had no working audio sink, and live imagery requests timed out
inside the emulator. Audible output, physical-console memory/performance, gyro
and stereo behavior remain unverified for this release. GitHub Actions remains
blocked by an account billing lock; reported test results are from the cloud
build environment.

## Compatibility and installation

Back up SD-card application data before upgrading. The CIA preserves title ID
`000400000FD34B00` and has title version 2.3.1, newer than the
v2.3.0 preview so installations can upgrade. For Homebrew Launcher, place the
3DSX at `sdmc:/3ds/3ds_google_maps/3ds_google_maps.3dsx`.

Friend codes require matching dataset versions. Older daily records remain in
their original file. Panoramax rounds still use SD imagery; tiled HD currently
applies to the experimental Google provider. Imagery coverage and availability
vary by provider. Menu language does not change map-image labels or install a
system keyboard. Regional font coverage, Indic shaping and emoji remain limited.

Release assets include CIA, 3DSX, SHA256SUMS and SOURCE_COMMIT. Verify downloaded
files against SHA256SUMS before installation.
