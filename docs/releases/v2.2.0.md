# Maps for Nintendo 3DS — v2.2.0 release notes (prepared)

*Major feature release following v2.0 — November 2026.*

v2.0 focused on the map viewer, offline map caching, GPS through a phone, search and routing. v2.2.0 expands Maps for Nintendo 3DS into a much bigger exploration and geography experience.

## Highlights

### Explore streets, not just maps
- Multi-provider Street View Explorer with Panoramax, optional Mapillary, KartaView and experimental Google/Bing integrations.
- Panorama search and navigation between available connected viewpoints, with a minimap and touchscreen directions.
- New 3DS gyro looking, calibration and smoothing; adjustable map-to-panorama fly-in transitions.
- Higher-resolution panorama detail in a view-selected central patch on supported Google imagery, with progressive loading and a fallback when detail is unavailable.

### Explore Earth in 3D
- Rotatable and zoomable Earth globe using NASA Blue Marble; on-demand NASA GIBS image detail where available, plus optional stereoscopic rendering.
- Selected-location elevation using online Terrarium tiles, with adjustable 3D orbit and zoom.
- Optional 3D buildings from OpenStreetMap footprints, with basic extrusion and available height data. No invented buildings where coverage is missing.

### StreetGuess — new geography gameplay
- Classic five-round World / United States / Europe guessing with moving, No Move and NMPZ rules, timers, pin placement, distance scoring and saved records.
- Curated versioned **32-location, 21-country** Panoramax dataset for daily, friend and local challenges.
- Daily Challenges with three difficulty modes, local daily/weekly records and recent history.
- Shareable challenge codes that reproduce the same locations, seed and rules.
- Pass-and-play sessions for **2–4 people** on one console.
- Country Streak that continues beyond five correct guesses, saves personal bests and has regression coverage for 12-answer runs and older-save compatibility.
- Mystery Landmark Expeditions, Surprise Me and additional exploration activities.
- Retry behavior for unavailable curated imagery without consuming a round.

### Maps, GPS and personalization
- Improvements to live tiles, caching, offline regions and background download management.
- Better place/address search and coordinate handling, favorites and route visualization.
- GPS following with live heading/speed where provided, estimated route progress and rerouting logic. Full turn-by-turn voice or maneuver instructions are **not** advertised.
- Per-session private phone GPS pairing credentials and HTTPS certificate verification; private location and token values are omitted from ordinary status output.
- Four customizable digital-button control profiles, accessibility-related text/contrast options and gyro settings.

## Known limits to disclose

- The production CIA/3DSX have passing local builds and host tests, but **physical original 3DS/New 3DS acceptance, gyro and stereoscopic testing remain unverified**.
- Provider availability varies. Google and Bing use experimental integrations with unresolved authorization requirements; classic random StreetGuess relies on Google. Curated challenges use Panoramax and are geographically limited.
- The globe is a historical Earth composite, not a live satellite video. Panorama detail covers a central patch; terrain uses one elevation tile at a time; buildings use simple available OSM geometry.
- A local self-signed certificate can prevent phone GPS pairing in some browsers; keep private pairing QR codes private.
- Public OSM/Nominatim/other demonstration-service usage and older curl dependency advisories still require attention before representing the release as security- or provider-cleared.
- A final stable GitHub Release has **not yet been created**. These notes and the source branch are a release-ready documentation draft, not evidence of publication.
