Open **R → Explore** to find the rotatable Earth globe, Grand Canyon terrain with stereo slider support, and two linked Bethesda street panoramas.

The globe hands off to the existing 2D map. Terrain is limited to the included region and does not include buildings. Street photos are bundled CC BY 4.0 captures.

This is a hardware-test preview. Host checks and Azahar checks were performed. Physical Old 3DS frame rate, slider comfort, gyro behavior, and prolonged memory use remain pending. See the source branch's Explore guide for credits and design details.

Install the CIA with FBI, or place the 3DSX at `sdmc:/3ds/3ds_google_maps/3ds_google_maps.3dsx`.
